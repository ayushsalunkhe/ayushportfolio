Featured Project

Memoria AI

An offline, AI-powered personal knowledge OS for Windows. Scan local folders, then search your documents by meaning — not filename — through natural language. A Spring Boot + Java 21 pipeline (scan → extract → embed → vector search) over an embedded H2 database and a Lucene index, with local Ollama embeddings. The entire stack ships inside the installer — no Docker, no database to set up, no cloud, no telemetry.

Mobile Safety • Computer Vision

DriverGuard

Cross-platform mobile safety app using Flutter and MediaPipe Face Mesh to detect driver drowsiness in real time via the Eye Aspect Ratio algorithm. Triggers audio/visual alerts, logs sessions offline in SQLite, and dispatches live GPS location to emergency contacts past a configurable threshold.

Problem

Fatigue detection has to run on-device and offline — a network round-trip is too slow to matter.

Approach

Eye Aspect Ratio computed over MediaPipe Face Mesh landmarks, straight from the front camera.

Result

Real-time alerts, offline session history, and automatic GPS dispatch past a set threshold.
